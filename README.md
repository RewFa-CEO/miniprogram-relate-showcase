# 认识 TA · 公开切片

> **认识 TA** 是一个微信小程序：把两个人的关系测评放在**同一把尺**上，落差一眼可见。
>
> **本仓库不是完整应用** —— 它是完整应用公开出来的**算法层切片**：3D 投影引擎、题库计分、双人对照。
> 应用外壳、云函数、AI 编排、知识库全文、竞品研究与内部文档都不在公开范围内（边界见 [`docs/SLICE.md`](docs/SLICE.md)）。

MIT 开源。`src/` 里是**逐字未改**的真实源码，不是重写版。

## 这个切片里有什么

| 模块 | 行数 | 作用 |
|---|---:|---|
| `src/chart3d.js` | 602 | **Canvas 2D 手写 3D 投影引擎**（零依赖、无 WebGL）：相机、投影、画家算法、叠尺与粒子群渲染 |
| `src/persona.js` | 188 | 双人同轴对照：把两个人在四条人格轴上的位置算出来，落差 = 两点距离 |
| `src/quiz.js` | 270 | 动态题库：权重表、维内权重削峰、试卷组卷 |
| `src/ai-bank.js` | 377 | 题库种子（内容由大模型基于心理学研究全文生成后过结构与合规校验） |
| `src/mbti.js` | 88 | MBTI 加权计分（加权多数 → 四轴方向 + 强度） |
| `src/style.js` | 102 | 沟通风格六维（0-3 档）+ 关系需求四组（0/1）计分 |
| `src/relation.js` | 256 | 结构化对照：只产出**结构与数字**，不产出解读文案 |
| `src/tone.js` | 168 | 今日沟通色调：由落差最大的那一维决定「今天先做什么」 |

零运行时依赖：纯 CommonJS，Node ≥ 18，无 npm 包，无 `wx.*` 调用（小程序侧与云函数侧共用同一份）。

## 跑起来

```bash
git clone https://github.com/RewFa-CEO/miniprogram-relate-showcase.git
cd miniprogram-relate-showcase
npm test              # 15 个回归测试，全部零依赖
npm run build:demo    # 生成 demo/bundle.js（把 require 换成模块表引用）
npm run demo          # 起本地静态服务，打开 http://127.0.0.1:8173/demo/
```

`npm test` 覆盖三类可验证主张：

- **3D 投影是纯数学** —— 同一世界坐标投影结果一致（纯函数）、近远点深度可分（画家算法前提）；
- **计分是确定的加权多数** —— 全选第一极 = `ESTJ`、全选第二极 = `INFP`、单题权重占比被削峰到 60% 以内（防止极端权重绑架一个维度）；
- **落差由可解释规则触发** —— 差异只可能来自 `mbti` 极性 / `style` 档位差 ≥ 2 / `need` 选项不同三类之一；同一个人对同一个人零差异。

## 三个值得单独说的设计决定

**1. 3D 花在数据上，不是虚拟化上。**
竞品把 3D 花在虚拟形象身上，数据还是平面文字。这里 3D 承载的是**同轴对照**：四条轨、两个测针、一段跨距块，拖动就能看清两个人在哪一维上分开了。渲染全部手写 —— 相机、投影、深度排序、Catmull-Rom 样条、boids-lite 粒子群，一个依赖都没有，因为小程序包体与稳定性优先。

**2. 只产出结构，不产出文案。**
`relation.js` 只给「哪几维不同、差多少、参考分多少」；所有人类可读的解读由云端大模型基于这份结构生成并缓存。算法层不造假话 —— 本地开发模式下页面显示「AI 解读需要云端」的占位，而不是塞一段假解读。

**3. 缺省值要守得住一致性。**
老档案只有 `axes` 没有 `axisScores` 时，强度缺省**不能取 50** —— 50 会被位置判定翻到第二极，出现「MBTI 写 ESTJ、胶囊却显示 I」的自相矛盾。代码里按方向取偏置值（70），并在测试里锁住这条。

## 切片边界

| 公开 | 不公开 |
|---|---|
| 算法层源码（`src/`） | 应用外壳（页面、云函数、AI 编排） |
| 回归测试 | 知识库全文（第三方出版物文本） |
| 可运行 demo | 竞品逆向研究、业务策略、运营文档 |
| 题库种子（自研 AI 生成） | 真实用户数据、账号、密钥 |

> 完整应用为**私有仓库**。这是刻意的：可公开的是「方法与实现」，不可公开的是「内容、数据与商业判断」。
> 本仓库出现的所有内容均为自有代码或自有生成文本，MIT 授权。
